# Snug — Project Conventions

## What This Is

Snug is a macOS menu bar utility that hides and organizes menu bar icons. It uses a hidden NSStatusItem as a "separator pusher" to collapse icons off-screen, with optional auto-hide timers, accessibility-powered item interaction, and a "Pocket" dropdown panel below the notch for accessing hidden items.

## Tech Stack

- **Language**: Swift 6.0, strict concurrency (`SWIFT_STRICT_CONCURRENCY: complete`)
- **Deployment target**: macOS 14.0 (Sonoma)
- **UI**: SwiftUI (preferences, onboarding) + AppKit (menu bar, status items)
- **Frameworks**: Foundation, Combine, ApplicationServices (AX API), Quartz (CGWindowList)
- **Auto-update**: Sparkle (`SPUStandardUpdaterController`)
- **Build system**: XcodeGen (`project.yml` → `Snug.xcodeproj`)
- **Testing**: Python 3 `unittest` (source/config consistency checks)

## Build & Run

```bash
# Generate Xcode project
xcodegen generate -f project.yml

# Build release
xcodebuild -scheme Snug -configuration Release build

# Run all Python tests
python3 -m unittest discover tests/

# Run a specific test file
python3 tests/test_issue_8_version_bump.py

# View debug logs (DEBUG builds only)
tail -f /tmp/snug-debug.log
```

No Makefile. `Snug.xcodeproj` is generated by XcodeGen and should not be edited directly.

## Code Patterns

### Concurrency
- All UI-touching classes are `@MainActor`
- Timed work uses `DispatchQueue.main.asyncAfter()` or `Task { @MainActor in ... }`
- Closures capture `[weak self]`

### State & Singletons
- `AppPreferences.shared` and `UpdaterController.shared` are `@Observable` singletons
- Persistence via UserDefaults (wrapped in AppPreferences)
- Models (`MenuBarItem`, `AutoHideInterval`, `HiddenItemInfo`) are `struct` + `Sendable`

### Naming
- Types: PascalCase (`StatusBarController`, `MenuBarItem`)
- Properties/functions: camelCase (`isCollapsed`, `refreshItems()`)
- Private storage: underscore prefix (`_logQueue`, `_initialValue`)

### Imports
- Explicit per-framework imports, no wildcard
- System frameworks first, clustered at file top

### Error Handling
- Non-throwing with `guard`/early return and optionals (`if let`, `as?`)
- Multi-level fallback (e.g., pressing items: PID tree walk → position-based AX → no-op)

### Logging
- Use `snugLog("message")` — writes to `/tmp/snug-debug.log` in DEBUG, no-op in release

## Version Management

Versions are defined in `project.yml` and interpolated elsewhere:
- `project.yml`: `MARKETING_VERSION` and `CURRENT_PROJECT_VERSION` (source of truth)
- `Snug/Info.plist`: uses `$(MARKETING_VERSION)` / `$(CURRENT_PROJECT_VERSION)` variables
- `Snug/Preferences/AboutSettingsView.swift`: displays via `Bundle.main.releaseVersionNumber`

When bumping versions, update `project.yml` and verify consistency — the Python test suite checks this.

## Key Architecture Notes

- **Separator pusher**: The collapse mechanism sets an NSStatusItem's width to ~10000pt, pushing items left of it off-screen. Not a window overlay.
- **Notch awareness**: Detects notch via `screen.safeAreaInsets.top > 0`; uses `auxiliaryTopRightArea` for safe boundary.
- **Multi-monitor**: Calculates min/max X across all `NSScreen.screens`.
- **Item discovery**: CGWindowList layer 25 (`kCGStatusWindowLevel`), filtered to windows > 2pt wide.
- **Accessibility**: Optional; enables item name resolution and off-screen pressing. Three fallback levels.
- **Auto-hide**: Timer (5s/10s/30s/1min) cancels on expand, restarts on collapse if enabled.
- **Pocket (notch dropdown)**: When enabled, hovering the notch area reveals a `NotchDropdownPanel` (NSVisualEffectView blur + CAShapeLayer border, grid layout) managed by `NotchDropdownCoordinator`. Dwell timer (300ms) triggers show; grace delay (200ms) prevents accidental hide. Panel shows/hides with 250ms/180ms animations.
- **`pocketEnabled`**: Persisted in `AppPreferences`; toggles Pocket feature on/off via `GeneralSettingsView`.
